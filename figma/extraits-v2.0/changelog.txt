12/09/2026 · Tokens (fondations)
• Nouvelle collection AMF Primitives (142 variables, mode Value) : échelles 50 → 900 façon Angular Material. Orange = Hot Orange actuel, Red = brique du thème Braise, Blue = Sky Blue, Steel = neutres froids actuels, Warm = neutres chauds de Braise, Green / Sunset / Amber / Crimson / Navy = feedback, palettes additionnelles Purple / Violet / Yellow / Light Grey / Shiny Green / Shiny Brown, alphas (Overlay 37, Black 8 / 12, White 12). Les valeurs de base sont reprises à l'identique des tokens AMF Theme existants. /  / • Nouvelle collection AMF Semantic (103 variables) avec 2 modes : Original (couleurs actuelles) et Braise (inspiré de la maquette ArcelorMittalGPT : brique #D22F14, bleu #0072CE, neutres chauds #FAF9F7 / #F4F3F0 / #3F3E3E). Tous les tokens sont des alias vers les Primitives. Groupes : Background, Text, Icon, Border, Action (Primary / Secondary / Neutral / Disabled / Selected), Feedback (Success / Warning / Error / Info / Neutral × Background / Border / Foreground / Solid), Tag (10 couleurs × Background / Border / Foreground). /  / • Nouvelle collection AMF Dimensions (33 variables) : Spacing 0 → 64 (grille 4 / 8, nommage numérique en px comme Material), Radius (None 0, XS 2, S 4, M 8, L 10 pour les conteneurs, XL 16, Full), Size (Control S / M / L = 32 / 40 / 48, Icon XS / S / M / L = 16 / 20 / 24 / 32, Touch Target 44, Badge Dot 8 / M 20), Border Width (Thin 1, Medium 2, Focus Ring 2). /  / • Scopes restreints par usage (fini ALL_SCOPES) : les pickers de couleur ne proposent que les tokens pertinents (fill, texte, stroke). /  / • Dark mode : prévu comme 2 modes supplémentaires (Original Dark, Braise Dark) sur AMF Semantic. Les composants 2026 ne consommant que des tokens sémantiques, le dark mode ne nécessitera aucune variante supplémentaire (contrairement au Theme=Light/Dark actuel géré par variant). /  / • Accessibilité : chaque token Text / Foreground est vérifié ≥ 4,5:1 sur son Background associé, Border/Input ≥ 3:1 sur Surface. Exception documentée : Action/Primary/Default en Original (#FF3700 avec texte blanc = 3,6:1) est conservé pour rester fidèle aux couleurs actuelles ; Braise corrige le point (#D22F14 = 5,05:1). En Braise, Warning passe en ambre pour ne plus être confondu avec l'orange de marque. Text/Placeholder et Text/Secondary utilisent des gris ≥ 4,5:1 (les gris 40 % / 60 % en alpha ne sont plus utilisés pour du texte). /  / • Les collections AMF Theme, Colors - Primary / Additionnal / Charts & Diagrams sont conservées telles quelles. À supprimer une fois les composants migrés.
